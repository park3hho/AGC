## 3. 하루 일정 (리서처 1명, 타오바오 탭 1개 기준)

- 오전: 공식몰 3~4곳 상품 목록 수집 → 후보 표 (가격·용량·한도·소비기한) 
- 오후: 가게당 집운 1회 확인 → 사진·옵션 수집 → 일괄 등록 30~40개

## 2-1. 마켓 등록 한도 (매니저 확인, 2026-11-22)

- **네이버**: 등록 한도 1,000개 (직전 3개월 판매액 500만 원·100건 미만 구간, 그룹상품은 1개로 셈). 현재 547개 → **남은 자리 약 450개**. 한도를 넘기면 15일부터 판매 이력 없는 상품이 판매중지된다.
  - 맛·용량 변형은 **그룹상품으로 최대한 묶는다** (B 묶음 '다른 맛·용량' 150개는 대부분 기존 그룹에 합칠 수 있음).
  - 그래도 넘치면 네이버는 **우선순위 상위 약 450개만** 올린다. 순서: A 크리스마스 → B 잘 팔린 브랜드 → C 마라 → D 과자 → E 차·커피 → F 예비.
  - 판매 이력 없는 기존 네이버 상품 정리(내리기)도 자리 확보 방법이지만, 내리기는 사용자 승인 후.
- **쿠팡**: 옵션 1,527개 / 한도 1만 개라 여유. 단 12-14부터 주간 신규 1,000개 한도.
- **자사몰**: 한도 없음, 600개 전부 등록.

## 4. 막힐 곳과 대책

1. **타오바오 계정 하나**: 리서치(eido_pur)와 결제(ediopur01)가 PC 하나를 번갈아 씀 → 리서치 시간을 정해 결제 점검과 겹치지 않게 (예: 10~13시·15~18시 리서치). 리서치용 브라우저 프로필을 따로 쓰는 게 가장 좋음.
2. **캡차·슬라이더**: 하루 상세 열람 70~100번이면 늘어남 → 가게 목록 페이지에서 가격·옵션을 최대한 읽고 상세는 등록할 것만 연다.
3. **사용자 검수 600개**: 묶음 검수 화면 + 상세 자동 초안 품질을 먼저 올린다 (디자이너).
4. **통관**: 육류·우지·견과·유제품 성분은 제외. 마라 소스류는 원재료표 확인 전 등록 금지.
