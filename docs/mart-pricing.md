# 배송비 별도형(마트형) 가격 기준 — 정리 (2026-11-21, 결정 진행 중)

지금은 정리만 해 둔 단계예요. 실제 등록·가격 반영은 리서치(낱개 구매 가능 여부·낱개 가격) 결과를 보고 결정해요.

## 1. 두 가지 가격 방식

| | 배송비 포함형 (included) | 배송비 별도형 (separate, 마트형) |
|---|---|---|
| 표시 | 무료배송 | 배송비 9,900원 (무료배송 기준 없음) |
| 가격 | 상품가 + 집운 운임 + 수수료 + 차익 2,000원 (마진 5% 바닥) | 낱개 값 = 낱개 원가 기준 마진 20% (수수료 뺀 뒤) |
| 판매 단위 | 박스·묶음 | 낱개 (여러 제품을 한 장바구니에, 배송비 한 번) |
| 대상 | 음료 전부 + 낱개 300g 이상 | 음료가 아닌 제품 중 낱개 계산무게(실무게·부피무게 큰 값) 300g 미만 |

- DB: `product.shipping_mode` (included · separate), `shipping_mode_source` (auto · manual), `unit_weight_g`, `unit_count` (BE 1909067, migration 54). 음료는 무게 상관없이 included 고정.
- 쿠팡·네이버는 상품 하나에 배송비 방식이 하나 → 별도형은 기존 박스 상품과 **따로** 올린다 (박스 상품은 그대로 둔다).

## 2. 별도형 가격 규칙

- 기본: 낱개 마진 20% (네이버 수수료 6.63%, 쿠팡 11.66% 뺀 뒤). 배송비 9,900원은 항상 받음, 5만 원 무료배송 안 함.
  - 이유: 5만 원 무료배송을 하면 마진 35~60%가 필요해 낱개 값이 비싸진다. 무료배송 없이 20%면 K-줌마(5만 원 무료배송)보다 모든 수량에서 싸다.
- 부피가 큰 제품(프링글스 등)은 25~30% — 많이 담으면 실제 운임이 9,900원을 넘어 마진이 떨어짐.
- 커뮤토(배송비 9,900원, 99,000원 이상 무료)는 이겨야 한다.

| 제품 | 낱개 값 | 커뮤토 낱개 환산 | 비고 |
|---|---|---|---|
| 레이즈 감자튀김 18g (429) | 450 | 550 | 120봉 주문도 이익 15% |
| 프리츠 41g (422) | 1,750 | 1,790 (중국 내수용 10개 17,900) | 낱개 마진 약 8%, 배송비 몫 포함하면 주문 전체로 더 남음 |
| 마라왕자 라탸오 550g (427) | 9,500 | 9,900 | 낱개 마진 약 19% |

- 쿠팡은 수수료가 커서 같은 이익이면 낱개 값이 8~10% 높다 (감자튀김은 480원이면 네이버와 비슷한 이익).

## 3. 낱개로 팔 때 가격 문제

1. 낱개 매입가가 박스보다 비쌀 수 있음 (박스 할인·묶음 할인이 빠짐). 낱개가 15% 비싸면 일부 제품은 20% 마진이 안 나옴.
2. 낱개 단위로 안 파는 판매처가 많음 (박스·세트만). 최소 구매 수량·1인 한도가 있을 수 있음.
3. 판매처 → 집운 창고 중국 내 배송비: 낱개 주문은 包邮(무료배송) 기준에 못 미쳐 판매처 배송비가 붙을 수 있음. 여러 판매처면 소포마다 붙음.
4. 집운 합포장: 소포가 많아지면 창고 입고를 기다리는 시간이 늘고(배송 지연), 소포·포장 처리비가 붙을 수 있음.
5. 부피무게: 여러 제품을 한 상자에 섞으면 상자가 커져 계산무게가 늘 수 있음. 봉지 과자 파손 위험·완충재.
6. 박스로만 살 수 있으면 남는 낱개는 재고(집운 재고)가 됨 → 유통기한·보관 위험.
7. 차 티백은 1개(티백 1봉)가 아니라 소포장 1박스(8개입 등)를 낱개로 봐야 함.
8. **(2026-11-22 확정) 판매 기본 단위 = 타오바오 판매처가 파는 최소 구성.** 1개로 쪼개지 않음(프리츠 8갑, 커비커 2·3·4캔). 더 필요하면 마켓 수량 선택으로. 박스 할인가 기준 1개 옵션은 만들지 않음 — 프리츠 1갑 옵션(쿠팡 4·네이버 4)은 이 이유로 2026-11-22 판매중지.
8. 수입신고: 한 주문에 품목이 많아지면 신고서 품목 줄이 늘어남.
